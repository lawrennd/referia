# Task: Pipeline DAG viewer + stage parameter panel on 11_multiverse

> Linked CIP: 0023.

## Description

On the formats `11_multiverse` page: render a Plotly (or HTML) DAG from
the pipeline manifest; let the analyst focus a stage and see its
parameters with cost-class badges; provide Checkboxes for the five
Phase 1 aggregate paper axes (and a note that whole-stage / refit ticks
come in Phase 2).

## Acceptance Criteria

- [ ] `/11_multiverse/` shows the connected pipeline
- [ ] Focusing a stage lists parameters from that stage’s `parameters.yml`
- [ ] Five paper-axis checkboxes persist via parameters / selection store
- [ ] Run passes active axes into `run_analysis_multiverse`
- [ ] Method text points at CIP-0023 / cost classes

## Implementation Notes

- Two-pane is fine if Plotly click→checkbox is awkward
- Do not mutate upstream stage `parameters.yml` when ticking axes
