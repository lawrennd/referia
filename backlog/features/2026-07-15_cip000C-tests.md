# Task: Tests for multi-config server and index query parameters

## Description

Write tests to cover the new root-server behaviour and index query parameter
resolution introduced by CIP-000C.

## Acceptance Criteria

- Path resolution: correct filesystem path derived from URL path and root.
- Path traversal rejection: `/../secret` returns HTTP 400.
- Missing config: HTTP 404 when no `_referia.yml` exists at the path.
- Explicit config filename: `/_referia_draft.yml` suffix is honoured.
- Index resolution:
  - Label string → correct record.
  - Integer `0` → first record.
  - Integer `-1` → last record.
  - Integer `n` (positive, within bounds) → `df.index[n]`.
  - Missing `index` parameter → defaults to first record.
  - Unknown label → HTTP 404.
- Reviewer cache: second request for the same path uses the cached reviewer.
- mtime invalidation: after the config file's mtime changes, the reviewer
  is reloaded on the next request.
- Two-config isolation: two configs loaded in the same test client have
  independent state.
- Landing page: `GET /` in root mode lists all discovered configs.
- Existing single-config tests continue to pass.
