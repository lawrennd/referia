# Task: Allow NumPy 2 by bumping spaCy 3.8 and en_core_web_sm

> **Scale note:** Backlog (not CIP). Consumer dependency bump so referia can install
> current lynguine `main` (`numpy >= 2.0.0`). No architecture or API change.

## Description

Referia pinned `numpy>=1,<2` because of [thinc#939](https://github.com/explosion/thinc/issues/939).
That issue is closed. spaCy 3.8 / Thinc 8.3 support NumPy 2. Referia was still frozen on
`en_core_web_sm-3.7.1` → spaCy 3.7.5 → Thinc 8.2.5 (`numpy<2`).

Lynguine 0.1.2 requires NumPy 2. The 2026-10-24 Dependabot lock refresh had to pin lynguine
at `8be6fcc` and leave pyarrow on 17.x for that reason.

## Acceptance Criteria

- [x] `pyproject.toml` requires `numpy >= 2.0.0` and spaCy 3.8 with `en_core_web_sm-3.8.0`
- [x] `poetry.lock` resolves NumPy 2, Thinc 8.3, spaCy 3.8, and current lynguine `main`
- [x] `poetry check` is clean
- [x] Test suite passes

## Implementation Notes

```bash
poetry update numpy spacy thinc en_core_web_sm lynguine pyarrow
poetry check
poetry run pytest tests/ referia/tests/ -q
```
