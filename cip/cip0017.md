## Summary

Surface each named Access store (especially `cache:`) in the review UI: loaded or absent, path, last-write time, size, compression, row count, column names. Use lynguine `store_stat` (lynguine CIP-0015) for file facts; use the already-loaded frame for catalogue. Label LLMManager diskcache separately as API-cost only.

Addresses [REQ-0011](../requirements/req0011_named-store-status.md). Display only — no new compute engine. Fits the existing `viewer:` / `review:` contract (CIP-0011); v1 can be Liquid/Markdown, not a Plotly widget.

## Motivation

Dialogue configs will persist bulky YAML (LLM payloads, optionally chunk `units`, embedding lists). `refresh: true` PopulateButtons and skip-if-field-present seed fit already treat cache/output as the source of truth. Today the reviewer has no in-interface signal that those files exist, how old they are, or what columns they hold. Stale extract cache then looks like a successful re-run.

Cache was always a **named store**. The gap is visibility, not a parallel checkpoint directory.

## Detailed Description

### What to show (per named store)

For `cache`, and optionally `output` / other durable stores the config lists:

| Fact | Source |
|------|--------|
| Role and config key (`cache`, `output`, …) | interface |
| Path | lynguine `store_stat` |
| Exists | `store_stat` |
| Last write (mtime, timezone-aware) | `store_stat` |
| Size (bytes + human) | `store_stat` |
| Codec (`gzip` or none) | `store_stat` |
| Index name, n_rows, column names | loaded CustomDataFrame (do not dump cell values) |

Do **not** render `extraction_payload`, embedding vectors, or unit text in this pane. Catalogue only.

### LLM diskcache is another line

If `LLMManager` has a diskcache directory, show one labelled line: “API cost cache; not analysis state.” Path optional. Never imply that deleting `_extract_cache.yml.gz` also clears the client cache, or the reverse.

### Skip vs first run

When the current row’s compute target field is already populated, the status pane (or the PopulateButton description) should make that visible — e.g. “cache hit on `extraction_payload` (written 2026-10-21 09:14)”. This is field presence + store mtime, not a hidden checkpoint fingerprint.

### UI placement

v1: a `viewer:` Liquid/Markdown block bound to a parameter field `store_status` (one mapping, not per-row series). Optional later: a typed CIP-0011 component `StoreStatus` if Liquid is too clumsy. Do not add a third layout column.

Precompute (once per serve) fills `store_status` from `store_stat` + frame catalogue. That precompute is referia convenience wrapping lynguine file facts — do not teach lynguine about review widgets.

### Cache policy (application, not this CIP’s IO)

This CIP displays whatever the config named. Sensible **use** of cache in dialogue YAML is specified on referia CIP-0015 / the application README:

- Persist cache when recompute is expensive (LLM extract).
- Do not also persist exploded copies of the same lists in cache.
- Cheap local segment: durable cache of `units` is optional once `chunks.yml` exists.
- Embeddings and packed arrays are **output**, compressed via lynguine CIP-0015, not cache-only.

### Non-goals

- Auto-delete stale cache.
- Diffing two cache generations.
- Editing cache from the status pane.
- Changing skip/refresh compute semantics (still field-in / field-out).

## Implementation Plan

1. Depend on lynguine `store_stat` (CIP-0015); until it lands, a referia wrapper may `stat` the confined path as a stopgap — document the stopgap.
2. Build a `store_status` mapping (parameters) at reviewer load / precompute.
3. Default Liquid snippet for dialogue drafts; optional widget type if CIP-0011 wants a typed entry.
4. Tests: missing cache file; present gzip cache; column names listed; payload text not in the rendered HTML.
5. LLM diskcache line only if that directory exists.

## Backward Compatibility

Configs without `cache:` show nothing new. Existing Liquid viewers unchanged unless they include the snippet.

## Testing Strategy

- Unit: mapping keys for a fake `store_stat` + empty vs non-empty cache frame.
- Render: Liquid/HTML contains mtime and column names, not embedding floats.
- Manual: `02_embed` with and without `_extract_cache.yml.gz`.
